# ATIG v2.0

Автономный ИИ-компаньон на Gemini. Веб-чат в браузере.

## Запуск на Render.com

1. Загрузить файлы на GitHub
2. Зайти на render.com
3. New → Web Service → выбрать репозиторий
4. Build Command: pip install -r requirements.txt
5. Start Command: python app.py
6. Environment Variables: GEMINI_API_KEY = ваш ключ
7. Deploy!
